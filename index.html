常见问题

装上之前，你可能想问的

需要联网吗？
不需要外部网络。只要设备连在同一个局域网内（同一路由器下的 Wi-Fi 或有线网络）就能同步。
需要注册账号吗？
不需要。下载安装后即可使用，没有账号体系，也不需要手机号或邮箱。
我的文件会经过你们的服务器吗？
不会。数据全程在局域网内点对点传输，我们不运营任何中转服务器，也不采集文件内容。
支持哪些平台？
支持 Windows、Linux 与 macOS（Apple Silicon）。移动端与更多平台会陆续补齐。
完全免费吗？
是。GNU GPL v3.0 开源，无广告、无内购、不做数据追踪；代码可在 GitHub 上自行审计。
