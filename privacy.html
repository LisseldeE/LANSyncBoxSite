LANSyncBox 隐私政策

最后更新日期：2026-09-14

引言

LANSyncBox（以下简称"本应用"）是一款局域网文件实时同步工具，致力于保护用户隐私。本隐私政策旨在说明本应用在信息收集、使用和保护方面的做法。

我们收集的信息

本应用不收集任何用户的个人信息。

  • 本应用不要求注册账户
  • 本应用不收集您的姓名、邮箱、地址、电话等个人身份信息
  • 本应用不收集设备标识符、位置信息、使用统计或其他设备信息

文件传输

  • 本应用的文件同步功能仅在局域网内进行
  • 文件内容直接在被授权的设备之间传输，不经过任何中间服务器
  • 文件不会被上传到云端或任何第三方服务
  • 传输使用您本地网络，应用开发者无法访问您的文件

网络请求

本应用仅在以下场景发起网络请求：

  1. 检查更新功能：当用户主动点击"检查更新"按钮时，应用会从开发者托管的 GitHub Pages 站点（lisseldee.github.io）拉取一个纯文本版本号文件。此请求仅查询版本号，不包含任何用户身份信息。
  2. 用户主动打开的网页链接：点击"查看详情""问题反馈"等链接时，系统浏览器会打开对应网页。

除此之外，本应用不会主动发起任何网络请求。

本地存储

本应用在用户设备本地（用户主目录下的 LANSyncBox 文件夹）存储以下内容：

  • config.json 配置：语言偏好（中文/英文）、固定房间号设置（用户主动启用时保存）、清理缓存开关、最近加入的房间记录（房间号与 IP，最多 3 条）、更新参考信息（版本号、程序路径、程序名称）
  • 同步文件夹（SyncFolder）：同步的文件，按房间号分子目录存放

以上信息仅保存在本地，不会上传到任何服务器，删除用户主目录下的 LANSyncBox 文件夹即可全部清除。

权限说明

本应用运行所需的权限：

  • 局域网访问权限：用于设备间的文件同步和房间发现
  • 文件系统访问权限：用于读写用户本地的同步文件夹
  • 网络访问权限：仅用于检查更新功能

本应用不会请求访问您的摄像头、麦克风、通讯录、位置等敏感权限。

第三方服务

本应用不集成任何第三方分析、广告或追踪服务。

检查更新功能访问的 GitHub Pages 与下载落地页（GitHub / Gitee Releases）受各自平台的隐私政策约束：

  • GitHub 隐私政策：https://docs.github.com/zh/site-policy/privacy-policies
  • Gitee 隐私政策：https://gitee.com/help/articles/4186

儿童隐私

本应用不针对 13 岁以下儿童，也不会有意收集儿童的个人信息。

数据安全

由于本应用不收集任何用户数据，因此不存在数据泄露风险。您的文件仅在本地网络传输，建议您在使用时确保局域网环境安全。

隐私政策变更

如果本隐私政策发生变更，更新后的政策将随应用新版本一同发布，并在本页面注明更新日期。

联系我们

如果您对本隐私政策有任何疑问，可通过以下方式联系开发者：

  • GitHub: https://github.com/LisseldeE/LANSyncBox

简而言之：本应用不收集任何用户个人信息，您的文件仅在您的局域网内传输，我们看不到您的任何数据。

LANSyncBox Pro 隐私政策

最后更新日期：2026-09-15

引言

LANSyncBox Pro（以下简称"本应用"）是一款局域网文件实时同步工具，支持同步模式、收集模式、投递、剪切板同步与房间自动发现，并内置公告推送与更新检查，致力于保护用户隐私。本隐私政策旨在说明本应用在信息收集、使用和保护方面的做法。

我们收集的信息

本应用不收集任何用户的个人信息。

  • 本应用不要求注册账户
  • 本应用不收集您的姓名、邮箱、地址、电话等个人身份信息
  • 本应用不收集设备标识符、位置信息、使用统计或其他设备信息

文件传输

  • 本应用的全部传输功能（同步模式、收集模式、投递、剪切板同步、文件会话通知、房间发现）仅在局域网内进行
  • 文件与剪切板内容直接在被授权的设备之间传输，不经过任何中间服务器
  • 文件内容不会被上传到云端或任何第三方服务
  • 传输使用您本地网络，应用开发者无法访问您的文件
  • 收集模式下，文件会按来源设备的 IP 在本机自动归档到对应文件夹，仅为便于整理，不会对外发送

剪切板同步

当您使用剪切板同步功能时，剪切板内容仅在同一房间内已被授权的设备之间通过局域网传输，不经过任何第三方服务器。

网络请求

本应用仅在以下场景发起网络请求：

  1. 公告推送功能：程序启动后，本应用会请求 GitHub Pages 上的公开纯文本公告文件（https://lisseldee.github.io/announcement/lansyncboxpro），读取公告版本号与正文用于界面展示。此请求仅下载公告内容，不包含任何用户身份信息或本机数据。您可在「设置 → 系统」中关闭"接收推送公告"以完全禁用此请求。
  2. 检查更新功能：当用户主动点击"检查更新"按钮，或开启"自动检查更新"时，应用会请求 GitHub Pages 上的公开纯文本版本文件（https://lisseldee.github.io/version/lansyncboxpro）获取最新版本号。此请求仅查询版本号，不包含任何用户身份信息。该功能仅存在于 GitHub / Gitee 开源版本中，微软商店版本不提供检查更新逻辑，也不会发起任何更新检查请求。
  3. 用户主动打开的网页链接：点击"查看详情""问题反馈""支持作者"等链接时，系统浏览器会打开对应网页。

除此之外，本应用不会主动发起任何网络请求。

本地存储

本应用在用户设备本地（用户主目录下的 LANSyncBox 文件夹）存储以下内容：

  • config.json 配置：语言偏好（中文/英文）、固定房间号设置（用户主动启用时保存）、清理缓存开关、最近加入的房间记录（房间号与 IP，最多 3 条）、最近一次接收的公告版本号与正文（仅在开启"接收推送公告"时保存）、更新参考信息（版本号、程序路径、程序名称）
  • 同步文件夹（SyncFolder）：同步/收集的文件，按房间号分子目录存放，收集模式下另按来源 IP 归档

以上信息仅保存在本地，不会上传到任何服务器，删除用户主目录下的 LANSyncBox 文件夹即可全部清除。

权限说明

本应用运行所需的权限：

  • 局域网访问权限：用于设备间的文件同步、投递、剪切板同步和房间发现
  • 文件系统访问权限：用于读写用户本地的同步文件夹
  • 网络访问权限：仅用于公告推送与检查更新功能
