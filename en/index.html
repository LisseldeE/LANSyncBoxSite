FAQ

Questions before you install

Do I need internet access?
No external network is needed. As long as the devices are on the same local network (same router, Wi-Fi or wired), they can sync.
Do I need an account?
No. Just install it and start using it — there is no account system, and no phone number or email is required.
Do my files pass through any server?
No. Data moves peer-to-peer inside your local network. No relay servers are involved, and file contents are never collected.
Which platforms are supported?
The Standard edition supports Windows and Linux; Pro adds macOS on top of that. Mobile and more platforms will follow.
What is the difference between Standard and Pro?
In the Standard edition one device acts as the hub while the others follow it. Pro is decentralized — there is no host to keep running; if any device drops out, the rest keep syncing with each other. Pro also adds six exclusive capabilities such as peer nicknames and permission control.
Is it completely free?
Yes. Open source under GNU GPL v3.0 — no ads, no in-app purchases, no data tracking. The code is on GitHub for anyone to audit.
